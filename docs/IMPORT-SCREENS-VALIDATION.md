# Отдельные экраны банка — проверка 0.4.6

Установите [APK 0.4.6](../artifacts/Finansist-0.4.6.apk) поверх приложения без удаления. VersionCode 16, схема SQLite 5.

1. Откройте «Настройки → Банковские уведомления → Настроить сбор». Здесь доступны выбор банка, разрешение Android, статус доступа и включение/пауза. Списка найденных операций здесь нет.
2. Откройте очередь кнопкой внизу «Финансов» или дождитесь нового push и вернитесь в приложение. Сразу после короткой шапки должны идти найденные операции. Выбора банка, разрешений и паузы здесь нет.
3. Проверьте изменение суммы/счёта/типа через «Проверить и подтвердить», отклонение, обновление и «Позже». До подтверждения баланс не меняется.
4. Откройте настройки сбора при ожидающих уведомлениях, затем вернитесь в приложение с корневой страницы. Само открытие настроек не должно пометить записи показанными или отключить автопереход для новых уведомлений.
5. Приостановите сбор в настройках. Уже найденные операции остаются в очереди и доступны для проверки. Возобновите сбор.
6. Если доступ Android не выдан, выдайте его из экрана настройки. После возврата должен обновиться статус. Новые уведомления не должны внезапно перебивать открытую настройку.
7. Проверьте оба экрана в светлой и тёмной теме и с увеличенным шрифтом.

Автоматические результаты — в ROADMAP.md. Физическая проверка интерфейса и системных разрешений на телефоне агентом не выполнена.
