# Покупки: проверка 0.5.2

Установите [APK 0.5.2](../artifacts/Finansist-0.5.2.apk) поверх приложения без удаления. VersionCode 19, SQLite-схема остаётся 6. Старые товары без количества для цены читаются как цена за 1 единицу. Количество позиций, назначения и отметки сохраняются.

1. Для добавления существующего товара нажмите «Выбрать из каталога». В каталоге создайте тестовую картошку: кг, количество для цены 1, цена 39 ₽. В список добавьте 0,1 кг — стоимость ≈ 3,90 ₽. Отдельных г/мл быть не должно; можно вводить 0.1 и 0,1.
2. Создайте тестовое филе: кг, количество для цены 0,45, цена 270 ₽. При выборе товара в списке по умолчанию предлагается 0,45 кг. Измените на 0,9: предпросмотр ≈ 540 ₽ ещё до сохранения. Для напитка 80 ₽ за 0,5 л количество 1 л даст ≈ 160 ₽.
3. В списке должны быть строки с названием, количеством, назначением и стоимостью, без карточек с тремя кнопками. Нажатие на название/стоимость открывает редактирование. Корзина справа работает отдельно от перехода.
4. Отметьте первую позицию корзиной: текст зачёркнут, корзина выделена, товар остаётся на месте. Стоимость списка, разбивка по бюджетам и прогноз не меняются. Повторное нажатие снимает отметку.
5. Нажмите строку → «Удалить из списка», подтвердите. Позиция удаляется из суммы, товар остаётся в каталоге. Можно удалить нежелательную позицию из любого списка.
6. В редактировании измените назначение для покупки: каталог сохраняет обычное назначение. Введите количество, выберите назначение/состояние, откройте «Изменить цену в каталоге», поменяйте цену или количество для неё. После возврата черновик позиции сохранён, предпросмотр обновлён, сохранение проходит.
7. Проверьте пустую цену: итог неполный, позиция без цены учитывается и после отметки корзиной. Явная цена 0 — известная бесплатная позиция.
8. «Есть дома» по-прежнему исключает позицию из прогноза. У неё корзина недоступна, строка открывает изменение/удаление. Верните состояние «Нужно взять» — позиция снова включается в сумму.
9. Сравните финансовые счета, журнал и распределения до/после изменений: никаких расходов, переводов или перераспределений от покупок не появляется.
10. Проверьте повторный запуск, оба цвета темы, увеличенный шрифт, экранную клавиатуру, попадание по корзине и прокрутку длинного списка. Удаление используемого товара или смена единицы по-прежнему блокируются с объяснением.

Цены приблизительные, без магазинов и автоматического обновления. Домашние запасы количественно не ведутся. Прогноз не суммирует остальные списки. Синхронизация, чеки и LLM в эту версию не входят.

Физический запуск APK агентом не проверен при недоступном устройстве; фактические автоматические результаты приведены в ROADMAP.md.


## Каталог и поиск 0.5.2

- На первом показе каталога отображается максимум 20 товаров. «Показать ещё 20» дополняет выдачу; запрос и обновление каталога возвращают первую порцию.
- Поиск проверяет все товары, включая те, которые ещё не были показаны. Сначала точное имя, затем начало имени, затем остальные совпадения. Регистр, ё/е и точка/запятая в названии не мешают поиску.
- Ниже совпадений — отдельная группа до 10 похожих по названию вариантов. При запросе с опечаткой могут быть только похожие. Совпадения со следующих страниц сюда не попадают. Если подходящих похожих меньше десяти, показываются имеющиеся; случайные позиции не подставляются.
- То же поведение доступно на отдельном экране выбора товара из формы позиции. Нажатие выбирает товар и возвращает к количеству; «+ Новый товар» возвращает к созданию нового. Ввод назначения, количества, цены за количество и отметка корзины работают как прежде.
- На большом каталоге проверьте подгрузку, выбор последнего товара через поиск, пустой запрос, пустой результат, оба цвета темы и увеличенный шрифт. Автоматически проверен сценарий с 1000 синтетических товаров; запуск на телефоне этим не заменяется.
