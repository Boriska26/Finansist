# Gemma 3 4B: только ингредиенты (2026-10-28)

Владелец разрешил проверить другое семейство моделей на компьютере. Проверена Gemma 3 4B Instruct Q4_K_M. Код приложения, APK и модель на телефоне не менялись; каталог и финансовые данные не использовались.

- Файл gemma-3-4b-it-Q4_K_M.gguf, 2489894016 байт (около 2,49 ГБ).
- Ревизия 5a3566e716d80f709ed7b79817eaf7733d2a1fce, SHA-256 04a43a22e8d2003deda5acc262f68ec1005fa76c735a9962a8c77042a74a7d19; проверен после загрузки и перед прогоном. Весов в Git нет, файл находится в .cache/llm. Лицензия Gemma; в APK кандидат не распространяется.

У Qwen в предыдущих опытах другие параметры: это сравнение пригодности конфигураций на одинаковых запросах, а не изоляция одной лишь архитектуры.

## Основные четыре запроса

Точно те же вопросы, что в docs/LLM-INGREDIENT-NAMES.md. Например:

> Какие ингредиенты нужны для обычного домашнего борща? Напиши только названия продуктов, без количества, цен и пояснений.

Никаких порций, количества, цен, единиц, JSON, доступа к SQLite или дополнительных рецептов в запросе нет. Все данные синтетические. Ответы ниже дословные; качество состава оценено вручную, автоматической полной кулинарной проверки нет.

| Блюдо | Время на компьютере | Оценка состава |
| --- | --- | --- |
| Борщ | 20,40 с | Свёкла, капуста, картофель, обычные овощи, бульон и приправы присутствуют; соль пропущена |
| Гречка по-купечески | 4,07 с | Пропущены мясная основа и морковь: исходный ответ неполный |
| Плов | 12,39 с | Рис, мясо, лук, морковь, чеснок и зира присутствуют; добавлен сахар, его необходимость следует проверить |
| Омлет с помидорами | 6,53 с | Правдоподобный обычный состав с молоком/сливками как альтернативой |

Все четыре ответа завершились естественно, CLI и диагностический скрипт вернули 0. Это успешное выполнение генерации, а не доказательство правильности всех ингредиентов. Первый холодный запуск загружал веса около 7,95 с; времена включают загрузку процесса/модели и не являются показателями S24 FE. На телефоне Gemma ещё не проверена.

## Дополнительное уточнение — отдельная проба

Вот список ингредиентов для гречки по-купечески с мясом:

Ответ завершился нормально. По журналу: загрузка 1,06 с, обработка запроса 1,32 с, генерация 9,90 с. Крупа, мясо, лук, морковь и масло появились; состав выглядит пригоднее. Эта проба не заменяет исходный неудачный ответ и не включена в основные четыре результата. Дополнительный запрос также не требовал количества или JSON.

## Вывод и ограничения

В этом небольшом прогоне Gemma дала более правдоподобный основной состав борща, плова и омлета, чем проверенные Qwen. При этом название «гречка по-купечески» без уточнения снова распознано неполно. Уточнение «с мясом» помогло. Один seed и пять запросов не подтверждают надёжность всех рецептов. Соль, сахар, альтернативы продуктов, количества, каталоговые названия и ограничения питания ещё требуют отдельной проверки.

Кандидат выглядит обнадёживающе для следующей итерации. Структурированный ответ, подключение к каталогу и генерация на S24 FE в этой работе не проверялись. Приложение остаётся на прежней модели.
