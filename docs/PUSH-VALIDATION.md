# Push ВБРР Онлайн: проверка 0.4.6

Установите [APK 0.4.6](../artifacts/Finansist-0.4.6.apk) поверх приложения без удаления. VersionCode 16, SQLite-схема 5. Счета, порядок, тема, операции и бюджет сохраняются.

## Подключение на S24 FE

1. Во вкладке «Настройки» в блоке «Банковские уведомления» нажмите «Настроить сбор». Откроется отдельный экран настроек.
2. Нажмите «Выбрать ВБРР Онлайн», затем выберите установленное приложение банка. Сбор будет включён для этого источника.
3. Нажмите «Разрешить доступ». Android откроет системные настройки. Найдите «Финансист — банковские уведомления» и разрешите доступ.
4. Вернитесь в приложение: статус должен показать разрешённый доступ. При необходимости вернитесь и снова откройте настройки сбора.
5. Дождитесь следующего обычного push ВБРР Онлайн. Старые записи истории банковского приложения автоматически не появятся. Специально выполнять реальную платную операцию ради проверки не требуется.
6. При входе в приложение новое уведомление откроет отдельную очередь проверки. Отложенные записи открываются кнопкой внизу «Финансов», после истории операций. На экране очереди нет настроек банка, доступа или переключателя сбора.

Если Android блокирует переключатель доступа из-за ограниченных настроек установленного APK, это требует отдельного решения пользователя в системных настройках приложения. Приложение не включает доступ самостоятельно. Статус доступа виден в настройках сбора.

## Проверка операции

Откройте «Проверить и подтвердить». Сверьте исходный текст, сумму, дату и счёт. По умолчанию используется верхний счёт из списка на момент получения; его можно заменить. Остаток из сообщения не должен подменять сумму операции или баланс приложения.

- **Оплата:** выберите категорию и назначение бюджета. Для аренды/рассрочки можно выбрать конкретное обязательство.
- **Списание СБП:** тип по умолчанию не выбран. Для перевода между своими картами выберите «Перевод» и второй счёт. Общая сумма денег не должна измениться.
- **Поступление:** проверьте доход. Только если это зарплата/аванс, включите «После сохранения предложить распределение».
- **Нераспознанная сумма:** поле остаётся пустым, баланс из push не подставляется. Сумму можно ввести вручную.
- **Неподходящее сообщение:** нажмите «Это не операция — отклонить». Никаких изменений в журнале быть не должно.

Деньги меняются только после подтверждения. Пока запись находится в очереди, общий баланс и бюджет сохраняют прежние значения.

## Совпадения и переводы

Перед подтверждением приложение ищет совпадения. Можно нажать «Проверить совпадения с журналом» вручную.

Если операция уже внесена, выберите «Уже в журнале: …». Подтверждение свяжет push с этой записью. Доход/расход второй раз не создаётся. Категория и назначение существующей записи не переписываются.

Если совпадение случайное, выберите «Создать отдельную новую операцию» и подтвердите предупреждение. Одна сумма и близкое время сами по себе не доказывают дубль.

Если увидите оба уведомления о переводе между своими счетами, создайте один перевод по первому. Второе свяжите с ним; при необходимости сначала поправьте счёт, чтобы он соответствовал входящей стороне.

Точная повторная доставка того же push не должна создавать новую строку после подтверждения или отклонения. Уведомления с другим идентификатором/временем либо изменённым текстом могут появляться отдельно для проверки.

## Сохранение и фоновая работа

Проверьте очередь после перезапуска приложения и в авиарежиме. Неподтверждённые записи должны остаться. Проверьте получение нового push при закрытом окне приложения, затем откройте его и обновите очередь.

После принудительного «Остановить» в настройках Android сбор может не работать до повторного запуска/восстановления доступа. Ограничения батареи или работы фоновых служб тоже могут влиять на доставку. Непрерывную работу на конкретном телефоне нужно проверить отдельно.

«Приостановить сбор» прекращает накопление новых сообщений и не очищает очередь. После включения сообщения из периода паузы автоматически не импортируются.

## Ограничения первой версии

- Один выбранный источник ВБРР Онлайн и известные русские/латинские форматы RUB.
- Дата предлагается по push; время внутри текста показывается для проверки. При задержке доставки дату можно изменить.
- История внутри банка и SMS не читаются. Сводные групповые уведомления пропускаются.
- Сообщение с несколькими операциями требует ручного разбора; сумма не угадывается.
- Исходный текст остаётся в приватной SQLite. В Git, тестовые фикстуры и технические журналы реальное содержимое не копируется.
- Фоновая служба, реальный формат доставки и системные разрешения не проверены агентом на телефоне: устройство в ADB offline.

Автоматическая проверка использует вымышленные суммы, карты, имена и тексты. Результаты итоговой сборки и журналов указаны в ROADMAP.md.
