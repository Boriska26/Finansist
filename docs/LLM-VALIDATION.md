# Помощник покупок — эксперимент 0.8.1

Установите artifacts/Finansist-0.8.1.apk поверх текущего приложения, без удаления. Минимальная версия Android теперь 9 (API 28); S24 FE подходит по версии ОС и архитектуре. Модель в APK не включена.

## Проверка на телефоне

1. Откройте «Покупки» → «Помощник». Нажмите скачивание модели. Требуется около 1,9 ГБ свободного места и загрузка 1,83 ГБ; удобнее Wi-Fi. Оставьте экран открытым. Можно отменить и продолжить; при уходе/сворачивании работа отменяется с сохранением уже скачанной части.
2. После загрузки отключите интернет. Напишите «Омлет с помидорами», порций 2, нажмите «Составить список». Дождитесь предложения или используйте отмену. Скорость и расход памяти на S24 FE пока не измерены.
3. Проверьте названия и количества. Модель может ошибиться: это предложение для редактирования. При необходимости измените количество или удалите ненужный продукт. В интерфейсе только шт., кг, л; например, 0,1 кг означает 100 г.
4. Для знакомого товара выберите подходящую запись каталога. Точное совпадение имени и единицы привязывается автоматически, похожие названия требуют выбора. Можно открыть обычный поиск каталога. При смене единицы количество очищается — введите его заново.
5. Если товара нет, нажмите добавление в каталог прямо в строке. Откроется обычный редактор с названием и единицей. Укажите цену и количество для цены либо оставьте цену неизвестной. Сохраните товар: он появится в каталоге и привяжется к позиции черновика. Созданный вручную товар остаётся в каталоге даже при отказе от списка.
6. Измените назначение «Необходимое / Для себя», если требуется. Проверьте приблизительные суммы и прогноз остатка. Неизвестные цены отмечены отдельно, финансовые операции не создаются.
7. Нажмите «Сохранить как список». Откроется обычный список покупок. Проверьте состав, количество, назначение и отметку корзины. Убедитесь, что баланс счетов и журнал операций остались прежними.
8. Повторите с «Жаркое из курицы с картошкой на два дня» и «Гречка по-купечески». Оцените пригодность состава, количество, время ожидания, прокрутку и обе темы.
9. Попробуйте отменить обработку. Старый черновик должен сохраниться. Обычный уход со страницы тоже отменяет работу. Черновик хранится только в памяти процесса и может пропасть после закрытия приложения системой.
10. Удалите файлы модели отдельной кнопкой: каталог, списки и финансы сохраняются. Удаление приложения удаляет и модель; обычное обновление сохраняет её.

Для обратной связи достаточно указать запрос, длительность, странные предложения и что неудобно. Реальные банковские уведомления и финансовые данные для этой проверки не нужны.

## Границы первой версии

Инструкция 0.8.1 просит полный состав блюда, включая масло, соль и специи. Ограничения в 3–6 продуктов больше нет. Модель и её файлы прежние: для проверки новой инструкции повторное скачивание не нужно.

Один запрос, до 32 позиций, без истории чата, рецепта по шагам, анализа расходов и автосохранения. Модель не читает SQLite и не выполняет SQL. Приложение само сопоставляет ингредиенты с каталогом и считает по последним сохранённым ценам. Проверка JSON защищает формат, но не гарантирует правильный рецепт или разумное количество.

Используется CPU, четыре потока, контекст 4096, ответ до 2048 токенов, лимит обработки пять минут. После генерации модель выгружается из памяти. Сеть используется только для скачивания публичного файла весов; пользовательские запросы не отправляются. Модель хранится в закрытой папке приложения, отдельно от SQLite.

## Фактические проверки на компьютере

- 236 тестов прошли: `./scripts/test.sh --offline --in-process`. Реальная SQLite, атомарное сохранение, отсутствие финансовых изменений, создание товара из черновика, смена единиц, отмена/ошибки, ревизии, возобновление загрузки и неверный SHA-256. В unit-тестах модель заменена синтетической реализацией.
- Настоящий C# → C ABI → llama.cpp → официальный GGUF проверяется через `./scripts/test-local-llm.sh` на борще, гречке по-купечески, плове и омлете (по пять порций). Валидация формата не подтверждает полноту состава: она оценивается отдельно по фактическим ответам. Фактические результаты расширенной инструкции всё ещё неудовлетворительны: борщ без свёклы и капусты, гречка по-купечески без мяса. Расширение инструкции не подтвердило улучшение качества; это сборка для сравнения, а не исправленный генератор рецептов. Три ответа разобраны (19,43–39,84 с на компьютере), плов отклонён из-за дубля ингредиента. Скрипт завершился с кодом 1; успешным этот smoke-прогон не считается. Нативная отмена прошла за 1,07 с.
- `./scripts/build-apk.sh --offline`: Android-сборка с анализаторами и `-warnaserror`, 0 предупреждений, 0 ошибок. APK включает arm64-v8a/x86_64 и лицензии, модель не включена. Подпись обновления совпадает с 0.8.0. Проверены SHA-256, zipalign с 16 КБ, ELF-выравнивание, экспорт C ABI и зависимости нативной библиотеки.
- Телефон в ADB offline; запуск интерфейса и нативный inference на Android агентом не выполнены.

## Сборка движка

Нужны .NET SDK 10, MAUI Android, SDK 36, JDK 21, CMake, Ninja/Make, curl, tar и NDK 27.3.13750724. Для этой рабочей копии NDK уже установлен в .cache/android-sdk. Для нового окружения можно указать имеющийся NDK через `FINANSIST_NDK` либо установить локально:

```bash
mkdir -p .cache/android-sdk/licenses
cp "$ANDROID_HOME"/licenses/* .cache/android-sdk/licenses/
"$ANDROID_HOME/cmdline-tools/latest/bin/sdkmanager" --sdk_root="$PWD/.cache/android-sdk" 'ndk;27.3.13750724'
./scripts/build-llm-native.sh
./scripts/build-apk.sh --offline
./scripts/test.sh --offline --in-process
```

Первый build-llm-native скачивает закреплённый архив исходников llama.cpp и проверяет SHA-256; дальнейшие сборки могут быть offline. build-apk автоматически вызывает сборку движка. Обычный dotnet build без подготовленных нативных библиотек недостаточен. .cache и бинарные результаты не коммитятся. Лицензии включены в native/finansist-llm и assets APK.

Для настоящего Linux smoke-теста нужен официальный файл Qwen3-1.7B-Q8_0.gguf (здесь уже скачан в .cache/llm). Можно указать его через `FINANSIST_TEST_MODEL`; скрипт проверяет хеш перед запуском:

```bash
./scripts/test-local-llm.sh
```

Источники: [официальная модель Qwen3-1.7B GGUF](https://huggingface.co/Qwen/Qwen3-1.7B-GGUF), [llama.cpp для Android](https://github.com/ggml-org/llama.cpp/blob/master/docs/android.md). Точные ревизии и хеши закреплены в коде и ARCHITECTURE.md.
