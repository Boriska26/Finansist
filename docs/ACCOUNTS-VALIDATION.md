# Счета: проверка 0.3.3

Установите [APK 0.3.3](../artifacts/Finansist-0.3.3.apk) поверх приложения без удаления. SQLite остаётся схемой 4; Android versionCode 7.

1. Откройте «Финансы». При первом открытии виден первый счёт, остальные скрыты.
2. Нажмите «Показать остальные». Удерживайте ручку ⋮⋮ справа на карточке счёта.
3. Перетащите счёт на верхнюю половину другой карточки, чтобы вставить перед ней, либо на нижнюю — после неё.
4. Поднимите нужный счёт первым и сверните список. Он должен остаться виден со своим остатком.
5. Перезапустите приложение: порядок и свёрнутое состояние должны сохраниться. Отдельно проверьте сохранение раскрытого состояния.
6. Переименуйте счёт — выбранный порядок должен сохраниться. Новый счёт должен появиться в конце раскрытого списка.
7. Проверьте обе темы, увеличенный шрифт и прокрутку к истории операций.
8. Если счёт один или счетов нет, кнопка раскрытия не показывается.

Автоматические тесты проверяют сохранение в настоящей SQLite, повторное открытие, переименование/добавление/удаление, отклонение устаревшего порядка, перемещение вверх/вниз, сворачивание и сохранение прежнего UI при ошибке записи. Финансовый баланс при изменении порядка не меняется.

На момент проверки телефон в ADB имеет статус offline. Физический жест и Android UI на телефоне агентом не проверены; XAML и Android-код компилируются при сборке APK.

Результат: 89 тестов прошли; сборка с -warnaserror без предупреждений и ошибок. Подпись совпадает с 0.3.2, zipalign и SHA-256 проверены. Логи: artifacts/tests-accounts-0.3.3.log, artifacts/build-accounts-0.3.3.log.
