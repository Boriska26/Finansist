# Установка и отладка через Wi-Fi

Готовый APK уже является Debug-сборкой. Профиль VS Code находится в `.vscode/launch.json`, команды подключения/установки — в `.vscode/tasks.json`. Настройки сверены со схемой установленного расширения .NET MAUI 1.17.289. Адрес телефона и код сопряжения в проект не сохраняются.

## Подключение и установка без кабеля (Android 11+)

1. Подключите телефон и компьютер к одной Wi-Fi сети. На телефоне включите параметры разработчика → **Беспроводная отладка** и разрешите её для текущей сети.
2. В обычном терминале компьютера из каталога проекта выполните:

   ```bash
   ./scripts/install-wifi.sh
   ```

3. На телефоне откройте **Сопряжение устройства с помощью кода**. Введите в терминале адрес `IP:порт` из этого окна, затем код по запросу ADB. Код не нужно присылать в чат.
4. После сопряжения вернитесь на основной экран **Беспроводная отладка**. Введите показанный там адрес `IP:порт`. Это **другой порт**, не порт сопряжения.
5. Скрипт проверит соединение, установит готовый APK и отправит команду запуска. При обновлении `adb install -r` сохраняет данные; скрипт не удаляет приложение при ошибках подписи.

Для уже сопряжённого телефона Enter пропускает сопряжение. Порт подключения может поменяться после выключения отладки или смены Wi-Fi — берите актуальный с телефона. Скрипт запускается в обычном терминале хоста, поскольку агентская песочница не разрешает ADB-серверу открыть локальный сокет.

Если нужен новый APK из изменённого кода:

```bash
./scripts/install-wifi.sh --build --offline
```

`--offline` относится только к NuGet-сборке, а не к Wi-Fi. Подключение и установка описаны в [официальной документации ADB](https://developer.android.com/tools/adb#connect-to-a-device-over-wi-fi).

## Отладка C# в VS Code

1. Откройте папку проекта. Расширение **.NET MAUI** уже обнаружено на текущем компьютере.
2. Выполните **Terminal → Run Task → Финансист: подключить телефон по Wi-Fi**. Оно запускает тот же мастер, но без установки APK.
3. В палитре команд выберите **.NET MAUI: Pick Android Device**, затем подключённый телефон. Если потребуется, выберите `Finansist.App` как стартовый проект.
4. Откройте, например, `src/Finansist.Core/ViewModels/AppViewModel.cs`, поставьте breakpoint в `SetThemeAsync`.
5. В панели Run and Debug выберите **Финансист — Android по Wi-Fi** и нажмите **F5**. Профиль использует MAUI-отладчик, Debug и `net10.0-android`. Устройство и транспорт берутся из выбора MAUI; при подключении телефона через ADB по Wi-Fi кабель не нужен.
6. На телефоне откройте настройки и смените тему — отладчик должен остановиться на breakpoint.

Сборку и развёртывание для F5 выполняет задача расширения `maui: Build`; обычная установка APK через ADB сама по себе C#-отладчик не подключает. Выбор Android-устройства и F5 описаны в [документации MAUI](https://learn.microsoft.com/dotnet/maui/get-started/first-app).

Если IDE не видит SDK: `.NET MAUI: Configure Android` → выберите Android SDK и JDK, затем Refresh Android environment. На текущем компьютере пути уже доступны через `ANDROID_HOME` и `JAVA_HOME`.

## Android 10 и ниже

Первичное включение ADB по TCP требует USB. Разрешите USB-отладку на телефоне, подключите кабель, выберите конкретный serial из `adb devices` и выполните `adb -s SERIAL tcpip 5555`. Затем отключите кабель и запустите `./scripts/install-wifi.sh --device IP_ТЕЛЕФОНА:5555`. Это отдельный сценарий из [документации Android](https://developer.android.com/tools/adb#wireless-android10-and-lower); скрипт не включает TCP-отладку на произвольном USB-устройстве автоматически.

## Что проверено

Проверены синтаксис Bash, JSON конфигураций и логика установщика с подставным ADB: успешный сценарий, недоступный телефон, ошибка установки и некорректный адрес. При недоступном телефоне установка не начинается; после ошибки установки приложение не запускается и не удаляется.

Реальное подключение, установка на телефон и остановка на breakpoint **не проверены**: при повторном запуске ADB в песочнице получено `could not install smartsocket listener: Operation not permitted`. Эти ограничения относятся к среде агента, а не к Debug APK.

## Исправление `startup project not found`

В журнале VS Code обнаружено, что телефон уже подключён, но запуск отменяется сообщением `Debugging canceled: startup project not found`. В установленном расширении MAUI 1.17.289 поиск проекта выполняется до подстановки переменных VS Code и использует точное сравнение пути. Поэтому `project: "${workspaceFolder}/…"` в прежнем launch.json приводил к отказу.

Поле project удалено из профиля и MAUI build-task: теперь они используют выбранный стартовый проект. Для C# Dev Kit явно задано решение Finansist.slnx. В Solution Explorer стартовым проектом должен быть **Finansist.App**. После обновления конфигурации повторите F5; при запросе проекта выберите Finansist.App. Если VS Code сохранил старое состояние, выполните Developer: Reload Window.

Поле connectionType также убрано: установленное расширение учитывает этот ручной override только для физических iOS-устройств, а Android-транспорт определяет по выбранному ADB-устройству. Повторное сопряжение телефона для исправления ошибки проекта не требуется.
